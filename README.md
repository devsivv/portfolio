## ⚡ Getting Started

### 1. Clone the repository

```
git clone https://github.com/devsivv/portfolio.git
cd portfolio
```

### 2. Install dependencies

```
npm install
```

### 3. Run development server

```
npm run dev
```

### 4. Build for production

```
npm run build
```
